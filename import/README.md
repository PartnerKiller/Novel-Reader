# Yuki Tales - Batch Import Directory

Place any `.txt` or `.epub` files directly into this directory (`import/`).

### How to Import:
1. **Via Admin Panel**:
   - Navigate to `/admin` -> **Story Management** -> Select **Batch Import Novels / Chapters**.
   - Click the **Server Directory (import/)** tab.
   - Click **Scan & Import from Server Directory**.
   - All `.txt` and `.epub` files found here will be parsed into novel series and chapters automatically.
   - Finished files are moved to `import/imported/`.

2. **Via Web Upload**:
   - In the Admin Panel -> **Batch Import Novels / Chapters** -> **Upload File**, you can directly upload `.epub`, `.txt`, or `.zip` files from your computer or phone.
